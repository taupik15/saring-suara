Ambil suaranya.
Redam musiknya.

Pisahkan vokal/instrumen dengan HTDemucs, atau dengarkan pratinjau percakapan melalui filter ringan. Semua pemrosesan lokal, tanpa upload file.

Filter frekuensi suara untuk pratinjau video/audio langsung. Bukan pemisahan musik dengan AI, dan belum menghasilkan file ekspor.

Mode ekspor RNNoise memuat FFmpeg WebAssembly. Pada iPhone, browser masih bisa menutup tab jika memori tidak cukup.

Model HTDemucs sekitar 52 MiB, ditambah memori WebAssembly untuk menjalankannya. Bahkan klip pendek bisa membebani iPhone.

Simpan sebagai

Efektif hanya jika percakapan berada di bagian tengah stereo. Tidak menjamin musik hilang.

Fix 1 mengurangi penumpukan memori melalui Worker terpisah, bukan menjamin HTDemucs kompatibel dengan semua iPhone. Untuk video 1 jam lebih dibutuhkan optimasi berikutnya (Fix 2). Preview Dialog ringan tidak setara dengan AI penghapus musik.
