Ambil suaranya.
Redam musiknya.

Putar video langsung dengan filter stereo, peredaman musik tengah, pengatur dialog −12 sampai +12 dB, AI GTCRN opsional, dan RNNoise real-time pada video. File media tetap di perangkat.

Pratinjau langsung tanpa konversi, tanpa FFmpeg dan tanpa HTDemucs. Tidak menjamin musik hilang; hasil bergantung pada posisi suara dalam rekaman stereo. Tidak menghasilkan file ekspor.

Pemisahan stereo ditambah estimasi latar musik yang stabil di tengah. Peredaman musik tengah bersifat eksperimental, bisa mengubah kualitas dialog, dan tidak dapat menjamin musik hilang seluruhnya. GTCRN atau RNNoise dapat membantu membersihkan noise secara real-time, tetapi bukan pemisah musik dan dapat mengubah warna suara.

Mode ekspor RNNoise memuat FFmpeg WebAssembly. Pada iPhone, browser masih bisa menutup tab jika memori tidak cukup.

HTDemucs memerlukan RAM besar dan terbukti me-refresh browser iPhone. Opsi ini tersedia untuk desktop saja.

Simpan sebagai

Efektif hanya jika percakapan berada di bagian tengah stereo. Tidak menjamin musik hilang.

Fix 1.9: RNNoise VAD terhubung ke gerbang suara adaptif. GTCRN dan RNNoise live opsional via WebAssembly lokal. Aset model dipaketkan saat deployment GitHub Actions, tanpa CDN saat pemutaran. Peredaman musik memakai filter stereo sebelumnya; AI hanya untuk meningkatkan kejernihan. Kualitas dan performa Safari iPhone 13 perlu diuji. Resume dan kontrol dB tetap ada.
